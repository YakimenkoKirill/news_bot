## Задача

Реализуй build_post(processed, news, source) -> Post(html, image_url, link): жирный заголовок, пустая строка, пересказ, пустая строка, строка хештегов, ссылка <a href=URL>Источник: имя источника</a>. Весь текст и атрибуты экранируются html.escape (quote=True); разрешены только теги b, a. Хранит отдельно части (title, summary, hashtags, link_html) для подрезки по длине.

**Критерий готовности:** Пост корректно отображается в Telegram в режиме HTML.

**Граничные случаи:** Символы <, >, &, кавычки в заголовке, пересказе и URL экранированы; нет хештегов -> строка не выводится; эмодзи сохраняются.

**Тесты** (`tests/unit/test_formatter.py`): эталонный пост, спецсимволы, кавычки в URL, без хештегов, эмодзи.

**Контекст проекта:** Python 3.11+, html.

**Файлы:** app/publisher/formatter.py, tests/unit/test_formatter.py.

**Стиль проекта:** ruff, mypy strict, docstrings Google Style; инварианты — из CLAUDE.md.

**Ограничения:** Ни один модуль, кроме app/config.py, не читает os.environ. Токены и ключи — SecretStr (не попадают в repr и логи). .gitignore не менять. Новые зависимости, заглушки (TODO, «...») и молчаливый except Exception: pass запрещены.

**Формат ответа:** Полные файлы: app/publisher/formatter.py, tests/unit/test_formatter.py. Тесты обязательны. Комментарии — только docstrings Google Style для сложных функций. После кода — таблица [Тест] -> [Критерий]. При нехватке данных сначала перечисли конкретные пробелы, значения не выдумывай (пороги и параметры — из configs/).
