## Задача

Реализуй AdRules (markers: list[str], skip_forwards: bool) и is_advertisement(message, rules) -> str | None — возвращает причину отсева: маркер из списка в тексте без учёта регистра или пересланное сообщение (fwd_from) при skip_forwards.

**Критерий готовности:** Рекламные и пересланные сообщения отсекаются по правилам из конфигурации.

**Граничные случаи:** Маркер внутри другого слова не срабатывает (границы слова); пустой текст не ошибка; skip_forwards=false пропускает пересланные.

**Тесты** (`tests/unit/test_telegram_ads.py`): каждый маркер, регистр, граница слова, пересланное с флагом и без, обычное сообщение.

**Контекст проекта:** Python 3.11+, re.

**Файлы:** app/collectors/telegram/ads.py, tests/unit/test_telegram_ads.py, configs/base.yaml, app/config.py.

**Стиль проекта:** ruff, mypy strict, docstrings Google Style; инварианты — из CLAUDE.md.

**Ограничения:** Ни один модуль, кроме app/config.py, не читает os.environ. Токены и ключи — SecretStr (не попадают в repr и логи). .gitignore не менять. Новые зависимости, заглушки (TODO, «...») и молчаливый except Exception: pass запрещены. Новые ключи конфигурации добавь в configs/base.yaml и в типизированную секцию модели в app/config.py; ключи, помеченные «задаёт человек», не заполняй сам — если их нет в configs/base.yaml, перечисли пробел и остановись. Ключи этого шага: telegram.ad_markers = [`#реклама`, `erid`]; telegram.skip_forwards = true.

**Формат ответа:** Полные файлы: app/collectors/telegram/ads.py, tests/unit/test_telegram_ads.py, configs/base.yaml, app/config.py. Тесты обязательны.
