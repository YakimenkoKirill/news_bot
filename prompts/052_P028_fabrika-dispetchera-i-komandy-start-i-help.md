## Задача

Реализуй в app/bot/__init__.py create_bot(settings) (DefaultBotProperties parse_mode=HTML) и create_dispatcher(deps) — подключает AdminOnlyMiddleware и роутеры, передаёт зависимости через workflow_data. app/bot/handlers/common.py: /start (приветствие и меню) и /help (список команд с описаниями из texts.py). Регистрирует команды в меню через set_my_commands.

**Критерий готовности:** Админ получает приветствие и полный список команд.

**Граничные случаи:** Неизвестная команда -> подсказка /help; список в /help совпадает с set_my_commands.

**Тесты** (`tests/unit/test_bot_common.py`): /start, /help, неизвестная команда, совпадение списков команд.

**Контекст проекта:** Python 3.11+, aiogram 3.x (Router, Dispatcher).

**Файлы:** app/bot/__init__.py, app/bot/handlers/common.py, app/bot/texts.py, tests/unit/test_bot_common.py.

**Стиль проекта:** ruff, mypy strict, docstrings Google Style; инварианты — из CLAUDE.md.

**Ограничения:** Ни один модуль, кроме app/config.py, не читает os.environ. Токены и ключи — SecretStr (не попадают в repr и логи). .gitignore не менять. Новые зависимости, заглушки (TODO, «...») и молчаливый except Exception: pass запрещены.

**Формат ответа:** Полные файлы: app/bot/__init__.py, app/bot/handlers/common.py, app/bot/texts.py, tests/unit/test_bot_common.py. Тесты обязательны. Комментарии — только docstrings Google Style для сложных функций. После кода — таблица [Тест] -> [Критерий]. При нехватке данных сначала перечисли конкретные пробелы, значения не выдумывай (пороги и параметры — из configs/).
