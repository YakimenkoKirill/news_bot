## Задача

Реализуй TelegramCollector (компонент с start/stop): при старте подключает клиент, читает включённые источники типа tg, вызывает catch_up() — для каждого канала догружает сообщения с min_id = max_tg_message_id(source_id), не больше catch_up_limit, — затем регистрирует обработчик NewMessage для этих каналов: отсев рекламы -> AlbumBuffer -> message_to_raw_item -> add_if_new + SourceHealthTracker. reload_sources() перерегистрирует обработчик после изменения источников. stop() вызывает flush_all и отключает клиент.

**Критерий готовности:** Новые посты тестовых каналов попадают в БД; после перезапуска пропущенное догружается без дублей.

**Граничные случаи:** Канал, который не удалось разрешить, получает ошибку в SourceHealthTracker и не мешает остальным; вызовы Telegram идут через with_flood_wait.

**Тесты** (`tests/unit/test_telegram_collector.py`): догрузка с min_id, обработчик нового сообщения, альбом, реклама, перезагрузка источников, ошибка одного канала (фейковый клиент).

**Контекст проекта:** Python 3.11+, Telethon events.

**Файлы:** app/collectors/telegram/collector.py, tests/unit/test_telegram_collector.py, configs/base.yaml, app/config.py.

**Стиль проекта:** ruff, mypy strict, docstrings Google Style; инварианты — из CLAUDE.md.

**Ограничения:** Ни один модуль, кроме app/config.py, не читает os.environ. Токены и ключи — SecretStr (не попадают в repr и логи). .gitignore не менять. Новые зависимости, заглушки (TODO, «...») и молчаливый except Exception: pass запрещены. Новые ключи конфигурации добавь в configs/base.yaml и в типизированную секцию модели в app/config.py; ключи, помеченные «задаёт человек», не заполняй сам — если их нет в configs/base.yaml, перечисли пробел и остановись. Ключи этого шага: telegram.catch_up_limit = 100.

**Формат ответа:** Полные файлы: app/collectors/telegram/collector.py, tests/unit/test_telegram_collector.py, configs/base.yaml, app/config.py. Тесты обязательны. Комментарии — только docstrings Google Style для сложных функций. После кода — таблица [Тест] -> [Критерий].
