# Шаг 109 из 113 · P061 · Этап 18 — Качество канала

**Задача трекера:** Иностранные источники
**Результат:** Модель корректно пересказывает на русском новости из англоязычных источников; проверка фактов учитывает язык
**Коммит:** `feat(ai): пересказ иностранных источников на языке канала`
**Как запустить:** откройте репозиторий в Claude Code и напишите: «Выполни @prompts/109_P061_podderzhka-angloyazychnyh-istochnikov.md». После коммита: `python prompts/next_step.py --done`.

## Задача

filters.allowed_languages = ["ru"] — это ключ «задаёт человек», значение в этом шаге не меняй. Подготовь код, чтобы человек мог добавить "en", и ничего не сломалось.

1. **Промпт** (пересказ и отбор, app/pipeline/ai/prompts.py): в пользовательском сообщении — строка «Язык источника: {lang}» (из news_items.language, которую уже определяет нормализация). В системном сообщении — правило: «Если язык источника отличается от языка канала — перескажи на языке канала; имена собственные и названия компаний передавай общепринятым написанием на языке канала, при сомнении — в оригинале в скобках». PROMPT_VERSION -> следующая версия.
2. **Проверка фактов** (unsupported_facts в app/pipeline/ai/factcheck.py): параметр `source_lang`. Если он совпадает с языком канала — как сейчас. Если нет — проверяются только числа (с нормализацией разделителей: 1,5 и 1.5; 1 000 и 1,000; «млрд» и «bn» не сравниваются как числа); имена не проверяются, а review_note дополняется пометкой «перевод из {lang}: имена не проверены автоматически».
3. **Модерация:** новый ключ `ai.review_foreign: true` — пересказы иностранных новостей идут на модерацию (pending_review), пока человек не убедится в качестве перевода.
4. **README.md:** как добавить англоязычные источники: добавить "en" в filters.allowed_languages, включить источники, первое время оставить ai.review_foreign = true.

**Критерий готовности:** После того как человек добавит "en" в allowed_languages, англоязычная новость проходит пайплайн, пересказ на русском, числа проверены, черновик приходит на модерацию.

**Граничные случаи:** Язык не определён -> как язык канала; русская новость -> поведение прежнее (промпт содержит строку языка, это ок); число в формате 1,000.5 -> нормализуется; review_foreign = false -> иностранные идут по режиму источника.

**Тесты:** `tests/unit/test_prompts.py` — строка языка и правило; `tests/unit/test_factcheck.py` — числа в разных форматах, имена пропущены для иностранного источника, прежнее поведение для русского; `tests/unit/test_ai_processor.py` — review_foreign.
