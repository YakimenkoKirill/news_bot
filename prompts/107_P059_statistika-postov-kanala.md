# Шаг 107 из 113 · P059 · Этап 18 — Качество канала

**Задача трекера:** Обратная связь из канала
**Результат:** Просмотры, пересылки и реакции опубликованных постов собираются через Telethon и попадают в отчёт
**Коммит:** `feat(stats): просмотры и реакции постов канала`
**Как запустить:** откройте репозиторий в Claude Code и напишите: «Выполни @prompts/107_P059_statistika-postov-kanala.md». После коммита: `python prompts/next_step.py --done`.

## Задача

Сейчас неизвестно, какие посты реально читают: оценка модели — единственный сигнал.

1. **Миграция 0009** (down_revision "0008"): в publications — views, forwards, reactions (Integer, NULL), stats_at (timezone-aware, NULL).
2. **Сбор:** метод `TelegramCollector.fetch_post_stats(channel_id: int, message_ids: Sequence[int]) -> dict[int, PostStats]` — `client.get_messages(channel, ids=[...])` пачками до 100; reactions — сумма count по `message.reactions.results` (0, если реакций нет); сообщение удалено -> отсутствует в результате. FloodWait — как в остальном коллекторе.
3. **Задача** `post_stats` раз в scheduler.stats_every_min: публикации со status = sent, stats_at IS NULL и published_at между now − stats.max_age_h и now − stats.delay_h -> собрать и записать. Посты старше max_age_h без статистики помечаются stats_at = now с NULL-значениями, чтобы не запрашивать вечно.
4. **Отчёт** (app/reports/daily.py и daily_format.py): блок «Читатели» за отчётный период по постам, у которых уже есть статистика: всего просмотров, средние просмотры поста, топ-3 по просмотрам (ссылкой), средние просмотры по источникам (в таблице источников — колонка не добавляется, строкой под таблицей: «просмотры на пост: Bell 1 240, Экономист 980»). Если статистики ещё нет — блок не выводится.
5. **Требование к человеку:** аккаунт Telethon должен видеть канал (быть его участником или админом). Если канал недоступен — лог `stats.channel_unavailable` и инцидент (тихий вид, без сообщения в чат), задача не падает.

**Критерий готовности:** Через сутки после публикации у поста есть просмотры, пересылки и реакции, и ежедневный отчёт показывает, какие посты и источники читают лучше.

**Граничные случаи:** Пост удалён из канала -> stats_at записан, значения NULL; канал недоступен аккаунту -> инцидент, задача не падает; реакции выключены в канале -> reactions = 0; повторный запуск не перезапрашивает уже собранные; публикация вне очереди учитывается так же.

**Тесты:** `tests/unit/test_post_stats.py` — сбор на fake-клиенте Telethon (пачки, удалённые, без реакций, FloodWait, недоступный канал); `tests/integration/test_repo_post_stats.py` — выборка публикаций для сбора и запись; `tests/integration/test_daily_report.py` и `tests/unit/test_daily_format.py` — блок «Читатели»; `tests/unit/test_scheduler.py` — задача.
