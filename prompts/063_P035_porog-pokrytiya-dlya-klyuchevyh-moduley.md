## Задача

**Критерий готовности:** make coverage проходит, каждый из трёх пакетов покрыт не меньше чем на 70%.

**Граничные случаи:** Скрипт падает с кодом 1 и списком пакетов ниже порога; отсутствие coverage.json -> понятная ошибка.

**Тесты** (`tests/unit/test_check_coverage.py`): расчёт по пакетам, пакет ниже порога, нет файла; плюс новые тесты для непокрытых веток.

**Контекст проекта:** Python 3.11+, pytest-cov, coverage.

**Файлы:** pyproject.toml, Makefile, scripts/check_coverage.py, tests/unit/test_check_coverage.py, новые тесты в tests/unit/.

**Стиль проекта:** ruff, mypy strict, docstrings Google Style; инварианты — из CLAUDE.md.

**Ограничения:** Ни один модуль, кроме app/config.py, не читает os.environ. Токены и ключи — SecretStr (не попадают в repr и логи). .gitignore не менять. Новые зависимости, заглушки (TODO, «...») и молчаливый except Exception: pass запрещены. Код приложения не менять: если тест находит баг — опиши его в итоговом списке для человека.

**Формат ответа:** Полные файлы: pyproject.toml, Makefile, scripts/check_coverage.py, tests/unit/test_check_coverage.py, новые тесты в tests/unit/. Тесты обязательны.
