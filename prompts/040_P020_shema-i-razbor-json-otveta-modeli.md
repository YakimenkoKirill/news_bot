## Задача

Реализуй AiResult (relevant: bool, score: float 0..1, title, summary, hashtags: list[str], category) с проверкой длины по ChannelProfile и parse_ai_response(content, profile) -> AiResult: снимает обёртку ```json ... ```, json.loads, валидация; хештеги приводятся к виду #слово (пробелы -> _, дубли удаляются, лишние сверх hashtags_max отбрасываются).

**Критерий готовности:** Корректный ответ превращается в AiResult; некорректный — в AiResponseError с причиной.

**Граничные случаи:** Невалидный JSON, нет ключа, score вне 0..1, пустой summary, title длиннее лимита -> AiResponseError; лишние ключи игнорируются.

**Тесты** (`tests/unit/test_ai_schema.py`): корректный ответ, обёртка ```json, каждый вид ошибки, нормализация хештегов.

**Контекст проекта:** Python 3.11+, pydantic 2.x, json.

**Файлы:** app/pipeline/ai/schema.py, tests/unit/test_ai_schema.py.

**Стиль проекта:** ruff, mypy strict, docstrings Google Style; инварианты — из CLAUDE.md.

**Ограничения:** Ни один модуль, кроме app/config.py, не читает os.environ. Токены и ключи — SecretStr (не попадают в repr и логи). .gitignore не менять. Новые зависимости, заглушки (TODO, «...») и молчаливый except Exception: pass запрещены.

**Формат ответа:** Полные файлы: app/pipeline/ai/schema.py, tests/unit/test_ai_schema.py. Тесты обязательны. Комментарии — только docstrings Google Style для сложных функций. После кода — таблица [Тест] -> [Критерий]. При нехватке данных сначала перечисли конкретные пробелы, значения не выдумывай (пороги и параметры — из configs/).
