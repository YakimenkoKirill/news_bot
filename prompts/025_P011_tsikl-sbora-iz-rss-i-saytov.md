## Задача

Реализуй app/collectors/runner.py: run_collection_cycle(now, deps) -> CycleReport. Берёт list_due(now), выбирает сборщик по типу из реестра {rss, web} (tg собирается событиями и здесь пропускается), обрабатывает источники параллельно не больше max_parallel_sources, сохраняет через add_if_new, вызывает mark_checked с новым fetch_state и SourceHealthTracker. Каждый источник — в своей сессии БД и в bind_context(source_id=...).

**Критерий готовности:** За один цикл обрабатываются все просроченные источники; CycleReport содержит число проверенных источников, новых новостей и ошибок.

**Граничные случаи:** Ошибка одного источника не останавливает остальные; PermanentCollectorError тоже засчитывается как ошибка; неизвестный тип источника -> ошибка этого источника, а не цикла.

**Тесты** (`tests/unit/test_collection_runner.py`): несколько источников, ошибка одного, лимит параллельности, пропуск tg, отчёт (фейковые сборщики и репозитории).

**Контекст проекта:** Python 3.11+, asyncio.

**Файлы:** app/collectors/runner.py, tests/unit/test_collection_runner.py, configs/base.yaml, app/config.py.

**Стиль проекта:** ruff, mypy strict, docstrings Google Style; инварианты — из CLAUDE.md.

**Ограничения:** Ни один модуль, кроме app/config.py, не читает os.environ. Токены и ключи — SecretStr (не попадают в repr и логи). .gitignore не менять. Новые зависимости, заглушки (TODO, «...») и молчаливый except Exception: pass запрещены. Новые ключи конфигурации добавь в configs/base.yaml и в типизированную секцию модели в app/config.py; ключи, помеченные «задаёт человек», не заполняй сам — если их нет в configs/base.yaml, перечисли пробел и остановись. Ключи этого шага: collectors.max_parallel_sources = 5.

**Формат ответа:** Полные файлы: app/collectors/runner.py, tests/unit/test_collection_runner.py, configs/base.yaml, app/config.py. Тесты обязательны. Комментарии — только docstrings Google Style для сложных функций. После кода — таблица [Тест] -> [Критерий]. При нехватке данных сначала перечисли конкретные пробелы, значения не выдумывай (пороги и параметры — из configs/).
