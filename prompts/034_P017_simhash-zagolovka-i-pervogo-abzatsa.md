## Задача

Создай app/pipeline/dedup.py: compute_simhash(title, text) -> int — 64-битный SimHash по шинглам из 3 слов от заголовка и первых first_paragraph_chars символов текста (нормализация как в content_hash); hamming(a, b) -> int; to_db(value) и from_db(value) для хранения беззнакового 64-битного числа в BIGINT со знаком.

**Критерий готовности:** Одинаковые тексты дают расстояние 0, незначительная правка — малое, разные новости — большое.

**Граничные случаи:** Короткий текст меньше 3 слов использует шинглы по одному слову; to_db/from_db — взаимно обратны для границ 0 и 2**64-1.

**Тесты** (`tests/unit/test_simhash.py`): идентичные, перефраз, разные тексты, короткий текст, обратимость to_db/from_db на границах.

**Контекст проекта:** Python 3.11+, simhash.

**Файлы:** app/pipeline/dedup.py, tests/unit/test_simhash.py, configs/base.yaml, app/config.py.

**Стиль проекта:** ruff, mypy strict, docstrings Google Style; инварианты — из CLAUDE.md.

**Ограничения:** Ни один модуль, кроме app/config.py, не читает os.environ. Токены и ключи — SecretStr (не попадают в repr и логи). .gitignore не менять. Новые ключи конфигурации добавь в configs/base.yaml и в типизированную секцию модели в app/config.py; ключи, помеченные «задаёт человек», не заполняй сам — если их нет в configs/base.yaml, перечисли пробел и остановись. Ключи этого шага: dedup.first_paragraph_chars = 300.

**Формат ответа:** Полные файлы: app/pipeline/dedup.py, tests/unit/test_simhash.py, configs/base.yaml, app/config.py. Тесты обязательны.
