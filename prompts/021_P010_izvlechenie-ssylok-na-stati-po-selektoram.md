# Шаг 021 из 070 · P010 · Этап 3 — Сборщики: RSS и сайты

**Задача трекера:** Сборщик сайтов без RSS
**Результат:** app/collectors/web_list.py: ссылки на статьи по селекторам
**Коммит:** `feat(collectors): извлечение ссылок на статьи по селекторам`
**Как запустить:** откройте репозиторий в Claude Code и напишите: «Выполни @prompts/021_P010_izvlechenie-ssylok-na-stati-po-selektoram.md». После коммита: `python prompts/next_step.py --done`.

## Задача

Реализуй app/collectors/web_list.py: модель WebSelectors (list_item, link, title — CSS-селекторы, extra=forbid) для поля sources.selectors; функция extract_links(html, base_url, selectors) -> list[ArticleLink(url, title)] на BeautifulSoup с парсером lxml: абсолютные URL через urljoin, порядок как на странице, без повторов.

**Критерий готовности:** Со страницы-фикстуры извлекаются все ссылки на статьи с заголовками.

**Граничные случаи:** Ссылки mailto:, javascript: и на другие схемы пропускаются; элемент без ссылки пропускается; невалидный селектор -> ValidationError при создании WebSelectors.

**Тесты** (`tests/unit/test_web_list.py`): две HTML-фикстуры, относительные ссылки, дубли, пропуск неподходящих схем, ошибочные селекторы.

**Контекст проекта:** Python 3.11+, BeautifulSoup4, lxml, pydantic 2.x.

**Файлы:** app/collectors/web_list.py, tests/fixtures/web/*.html, tests/unit/test_web_list.py.

**Стиль проекта:** ruff, mypy strict, docstrings Google Style; инварианты — из CLAUDE.md.

**Ограничения:** Ни один модуль, кроме app/config.py, не читает os.environ. Токены и ключи — SecretStr (не попадают в repr и логи). .gitignore не менять. Новые зависимости, заглушки (TODO, «...») и молчаливый except Exception: pass запрещены.

**Формат ответа:** Полные файлы: app/collectors/web_list.py, tests/fixtures/web/*.html, tests/unit/test_web_list.py. Тесты обязательны. Комментарии — только docstrings Google Style для сложных функций. После кода — таблица [Тест] -> [Критерий]. При нехватке данных сначала перечисли конкретные пробелы, значения не выдумывай (пороги и параметры — из configs/).
