## Задача

Реализуй в app/pipeline/normalizer.py: clean_html(text) -> str (BeautifulSoup.get_text с разделителем, html.unescape, схлопывание пробелов, сохранение абзацев как \n\n) и canonical_url(url) -> str (нижний регистр схемы и хоста, удаление порта по умолчанию, фрагмента и параметров из drop_query_params с поддержкой шаблонов вида utm_*, сортировка оставшихся параметров, удаление завершающего / кроме корня).

**Критерий готовности:** Одинаковые по смыслу URL приводятся к одной строке; HTML превращается в чистый текст с абзацами.

**Граничные случаи:** URL без схемы -> ValueError; IDN-домен сохраняется; пустой текст -> пустая строка; &nbsp; и неразрывные пробелы схлопываются.

**Тесты** (`tests/unit/test_normalizer_text.py`): таблица пар URL до/после, HTML с абзацами и сущностями, пустые входы.

**Контекст проекта:** Python 3.11+, BeautifulSoup4, urllib.parse.

**Файлы:** app/pipeline/normalizer.py, tests/unit/test_normalizer_text.py, configs/base.yaml, app/config.py.

**Стиль проекта:** ruff, mypy strict, docstrings Google Style; инварианты — из CLAUDE.md.

**Ограничения:** Ни один модуль, кроме app/config.py, не читает os.environ. Токены и ключи — SecretStr (не попадают в repr и логи). .gitignore не менять. Новые зависимости, заглушки (TODO, «...») и молчаливый except Exception: pass запрещены. Новые ключи конфигурации добавь в configs/base.yaml и в типизированную секцию модели в app/config.py; ключи, помеченные «задаёт человек», не заполняй сам — если их нет в configs/base.yaml, перечисли пробел и остановись. Ключи этого шага: normalize.drop_query_params = [`utm_*`, `fbclid`, `gclid`, `yclid`].

**Формат ответа:** Полные файлы: app/pipeline/normalizer.py, tests/unit/test_normalizer_text.py, configs/base.yaml, app/config.py. Тесты обязательны. Комментарии — только docstrings Google Style для сложных функций. После кода — таблица [Тест] -> [Критерий]. При нехватке данных сначала перечисли конкретные пробелы, значения не выдумывай (пороги и параметры — из configs/).
