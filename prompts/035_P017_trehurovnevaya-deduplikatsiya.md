## Задача

Дополни app/pipeline/dedup.py: Deduplicator(repo, cfg).check(item_id, fields, simhash, now) -> DedupResult(is_duplicate, duplicate_of, cluster_id, level: url | hash | simhash | None). Порядок: exists_url -> find_by_hash в окне window_h -> recent_simhashes в окне с расстоянием <= simhash_max_distance (выбирается ближайший). cluster_id дубля = cluster_id найденной новости или её id.

**Критерий готовности:** Дубль определяется первым сработавшим уровнем; уникальная новость получает собственный кластер.

**Граничные случаи:** Новость не сравнивается сама с собой; несколько кандидатов SimHash -> ближайший, при равенстве — более ранний; вне окна дубли не ищутся.

**Тесты** (`tests/unit/test_deduplicator.py`): каждый уровень, приоритет уровней, выбор ближайшего, окно, исключение самой себя (фейковый repo).

**Контекст проекта:** Python 3.11+.

**Файлы:** app/pipeline/dedup.py, tests/unit/test_deduplicator.py, configs/base.yaml, app/config.py.

**Стиль проекта:** ruff, mypy strict, docstrings Google Style; инварианты — из CLAUDE.md.

**Ограничения:** Ни один модуль, кроме app/config.py, не читает os.environ. Токены и ключи — SecretStr (не попадают в repr и логи). .gitignore не менять. Новые зависимости, заглушки (TODO, «...») и молчаливый except Exception: pass запрещены. Новые ключи конфигурации добавь в configs/base.yaml и в типизированную секцию модели в app/config.py; ключи, помеченные «задаёт человек», не заполняй сам — если их нет в configs/base.yaml, перечисли пробел и остановись. Ключи этого шага: dedup.window_h = 48; dedup.simhash_max_distance = 3 (стартовое значение, уточняется на шаге с eval_dedup).

**Формат ответа:** Полные файлы: app/pipeline/dedup.py, tests/unit/test_deduplicator.py, configs/base.yaml, app/config.py. Тесты обязательны. Комментарии — только docstrings Google Style для сложных функций. После кода — таблица [Тест] -> [Критерий].
