## Задача

Реализуй app/collectors/robots.py: RobotsChecker(http_client, user_agent, ttl) с методом async allowed(url) -> bool. robots.txt загружается через HttpClient, разбирается urllib.robotparser и кэшируется на домен на ttl.

**Критерий готовности:** Запрещённые для нашего User-Agent пути возвращают False; кэш не запрашивает robots.txt повторно в пределах ttl.

**Граничные случаи:** robots.txt 404 -> всё разрешено; 5xx или недоступен -> всё запрещено (как в RFC 9309); по истечении ttl файл перезапрашивается; параллельные вызовы для домена делают один запрос.

**Тесты** (`tests/unit/test_robots.py`): allow/disallow, 404, 5xx, кэш и его истечение, один запрос при параллельных вызовах.

**Контекст проекта:** Python 3.11+, urllib.robotparser, aioresponses.

**Файлы:** app/collectors/robots.py, tests/unit/test_robots.py, configs/base.yaml, app/config.py.

**Стиль проекта:** ruff, mypy strict, docstrings Google Style; инварианты — из CLAUDE.md.

**Ограничения:** Ни один модуль, кроме app/config.py, не читает os.environ. Токены и ключи — SecretStr (не попадают в repr и логи). .gitignore не менять. Новые зависимости, заглушки (TODO, «...») и молчаливый except Exception: pass запрещены. Новые ключи конфигурации добавь в configs/base.yaml и в типизированную секцию модели в app/config.py; ключи, помеченные «задаёт человек», не заполняй сам — если их нет в configs/base.yaml, перечисли пробел и остановись. Ключи этого шага: collectors.robots_ttl_h = 24.

**Формат ответа:** Полные файлы: app/collectors/robots.py, tests/unit/test_robots.py, configs/base.yaml, app/config.py. Тесты обязательны. Комментарии — только docstrings Google Style для сложных функций. После кода — таблица [Тест] -> [Критерий]. При нехватке данных сначала перечисли конкретные пробелы, значения не выдумывай (пороги и параметры — из configs/).
