## Задача

Реализуй PROMPT_VERSION (строка, например `v1`), ChannelProfile (topic, language, tone, max_title_chars, max_summary_chars, hashtags_max — из секции channel) и build_messages(news, profile) -> list[dict]. Системное сообщение: роль редактора канала, тематика, язык и тон, запрет добавлять факты, которых нет в источнике, требование пересказать своими словами без дословных цитат длиннее 15 слов, точный список ключей JSON (relevant, score, title, summary, hashtags, category) и ограничения длины. Пользовательское сообщение: заголовок, источник, дата и текст новости, обрезанный до max_input_chars по границе слова.

**Критерий готовности:** Промпт собирается из профиля канала и новости; версия доступна для записи в processed_posts.

**Граничные случаи:** Текст новости никогда не попадает в системное сообщение; обрезка не рвёт слово; профиль без обязательного поля -> ValidationError.

**Тесты** (`tests/unit/test_prompts.py`): наличие тематики и ключей JSON, обрезка, разделение system/user, версия.

**Контекст проекта:** Python 3.11+, pydantic 2.x.

**Файлы:** app/pipeline/ai/prompts.py, tests/unit/test_prompts.py, configs/base.yaml, app/config.py.

**Стиль проекта:** ruff, mypy strict, docstrings Google Style; инварианты — из CLAUDE.md.

**Ограничения:** Ни один модуль, кроме app/config.py, не читает os.environ. Токены и ключи — SecretStr (не попадают в repr и логи). .gitignore не менять. Новые зависимости, заглушки (TODO, «...») и молчаливый except Exception: pass запрещены. Новые ключи конфигурации добавь в configs/base.yaml и в типизированную секцию модели в app/config.py; ключи, помеченные «задаёт человек», не заполняй сам — если их нет в configs/base.yaml, перечисли пробел и остановись. Ключи этого шага: channel.topic, channel.language, channel.tone, channel.max_title_chars, channel.max_summary_chars, channel.hashtags_max — задаёт человек; ai.max_input_chars = 6000.

**Формат ответа:** Полные файлы: app/pipeline/ai/prompts.py, tests/unit/test_prompts.py, configs/base.yaml, app/config.py. Тесты обязательны. Комментарии — только docstrings Google Style для сложных функций. После кода — таблица [Тест] -> [Критерий]. При нехватке данных сначала перечисли конкретные пробелы, значения не выдумывай (пороги и параметры — из configs/).
