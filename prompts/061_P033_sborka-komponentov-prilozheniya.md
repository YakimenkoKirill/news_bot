# Шаг 061 из 070 · P033 · Этап 8 — Бот управления, модерация и сборка приложения

**Задача трекера:** Планировщик и сборка приложения
**Результат:** Сборка приложения в app/main.py
**Коммит:** `feat(app): сборка компонентов приложения`
**Как запустить:** откройте репозиторий в Claude Code и напишите: «Выполни @prompts/061_P033_sborka-komponentov-prilozheniya.md». После коммита: `python prompts/next_step.py --done`.

## Задача

Дополни app/main.py: build_components(settings) создаёт и связывает движок БД, HttpClient, AlertService, бота и диспетчер (компонент polling), TelegramCollector, DeepSeekClient, BotReviewNotifier и планировщик. Порядок запуска: БД -> HTTP -> бот -> Telegram-сборщик -> планировщик; остановка обратная: планировщик ждёт завершения задач, сборщик сбрасывает альбомы, сессия бота закрывается, движок освобождается.

**Критерий готовности:** python -m app запускает весь пайплайн и корректно останавливается по SIGTERM.

**Граничные случаи:** Ошибка авторизации Telethon при старте -> понятное сообщение и остановка уже запущенных компонентов; ни один компонент не создаёт свой event loop.

**Тесты** (`tests/unit/test_app_wiring.py`): порядок запуска и остановки, откат при ошибке Telethon, все зависимости связаны (фейки).

**Контекст проекта:** Python 3.11+, asyncio, aiogram 3.x, APScheduler 3.x.

**Файлы:** app/main.py, tests/unit/test_app_wiring.py.

**Стиль проекта:** ruff, mypy strict, docstrings Google Style; инварианты — из CLAUDE.md.

**Ограничения:** Ни один модуль, кроме app/config.py, не читает os.environ. Токены и ключи — SecretStr (не попадают в repr и логи). .gitignore не менять. Новые зависимости, заглушки (TODO, «...») и молчаливый except Exception: pass запрещены.

**Формат ответа:** Полные файлы: app/main.py, tests/unit/test_app_wiring.py. Тесты обязательны. Комментарии — только docstrings Google Style для сложных функций. После кода — таблица [Тест] -> [Критерий]. При нехватке данных сначала перечисли конкретные пробелы, значения не выдумывай (пороги и параметры — из configs/).
