# Шаг 054 из 070 · P029 · Этап 8 — Бот управления, модерация и сборка приложения

**Задача трекера:** Управление источниками через бота
**Результат:** Список источников и действия кнопками
**Коммит:** `feat(bot): список источников с inline-кнопками`
**Как запустить:** откройте репозиторий в Claude Code и напишите: «Выполни @prompts/054_P029_spisok-istochnikov-s-inline-knopkami.md». После коммита: `python prompts/next_step.py --done`.

## Задача

Реализуй app/bot/keyboards.py (CallbackData-фабрики SourceAction(action, id, page)) и app/bot/handlers/sources.py: /sources — список постранично по page_size с типом, именем, статусом и числом ошибок; кнопки «вкл/выкл», «удалить» (с подтверждением), «проверить» (пробный сбор). После изменения источников tg вызывается TelegramCollector.reload_sources().

**Критерий готовности:** Источниками можно управлять без доступа к серверу.

**Граничные случаи:** Пустой список -> подсказка /add_source; удаление без подтверждения невозможно; устаревший callback на удалённый источник -> сообщение «источник не найден».

**Тесты** (`tests/unit/test_bot_sources.py`): пагинация, переключение, удаление с подтверждением, устаревший callback, вызов reload_sources.

**Контекст проекта:** Python 3.11+, aiogram 3.x (CallbackData, InlineKeyboardBuilder).

**Файлы:** app/bot/keyboards.py, app/bot/handlers/sources.py, tests/unit/test_bot_sources.py, configs/base.yaml, app/config.py.

**Стиль проекта:** ruff, mypy strict, docstrings Google Style; инварианты — из CLAUDE.md.

**Ограничения:** Ни один модуль, кроме app/config.py, не читает os.environ. Токены и ключи — SecretStr (не попадают в repr и логи). .gitignore не менять. Новые зависимости, заглушки (TODO, «...») и молчаливый except Exception: pass запрещены. Новые ключи конфигурации добавь в configs/base.yaml и в типизированную секцию модели в app/config.py; ключи, помеченные «задаёт человек», не заполняй сам — если их нет в configs/base.yaml, перечисли пробел и остановись. Ключи этого шага: bot.page_size = 10.

**Формат ответа:** Полные файлы: app/bot/keyboards.py, app/bot/handlers/sources.py, tests/unit/test_bot_sources.py, configs/base.yaml, app/config.py. Тесты обязательны. Комментарии — только docstrings Google Style для сложных функций. После кода — таблица [Тест] -> [Критерий]. При нехватке данных сначала перечисли конкретные пробелы, значения не выдумывай (пороги и параметры — из configs/).
