## Задача

Напиши scripts/backup.py: pg_dump в формате custom (-Fc) в backups/ с меткой времени UTC, копия файла Telethon-сессии рядом, удаление бэкапов старше keep_days; пароль передаётся через переменную PGPASSWORD процесса pg_dump, а не аргументом; ненулевой код при ошибке. Логика — в функциях для тестов.

**Критерий готовности:** Скрипт создаёт дамп и копию сессии и удаляет старые бэкапы.

**Граничные случаи:** Ошибка pg_dump -> частичный файл удаляется и код 1; нет файла сессии -> предупреждение, дамп всё равно сохраняется; ротация не трогает чужие файлы в каталоге.

**Тесты** (`tests/unit/test_backup.py`): имена файлов, ротация по датам, ошибка pg_dump, нет сессии, пароль не в argv (subprocess замокан, tmp_path).

**Контекст проекта:** Python 3.11+, subprocess, pathlib.

**Файлы:** scripts/backup.py, tests/unit/test_backup.py, configs/base.yaml, app/config.py.

**Стиль проекта:** ruff, mypy strict, docstrings Google Style; инварианты — из CLAUDE.md.

**Ограничения:** Ни один модуль, кроме app/config.py, не читает os.environ. Токены и ключи — SecretStr (не попадают в repr и логи). .gitignore не менять. Новые зависимости, заглушки (TODO, «...») и молчаливый except Exception: pass запрещены. Новые ключи конфигурации добавь в configs/base.yaml и в типизированную секцию модели в app/config.py; ключи, помеченные «задаёт человек», не заполняй сам — если их нет в configs/base.yaml, перечисли пробел и остановись. Ключи этого шага: backup.keep_days = 7; backup.dir = backups.

**Формат ответа:** Полные файлы: scripts/backup.py, tests/unit/test_backup.py, configs/base.yaml, app/config.py. Тесты обязательны. Комментарии — только docstrings Google Style для сложных функций. После кода — таблица [Тест] -> [Критерий]. При нехватке данных сначала перечисли конкретные пробелы, значения не выдумывай (пороги и параметры — из configs/).
