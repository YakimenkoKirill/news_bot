## Задача

Перепиши README.md: назначение; требования; установка и запуск локально (make install, make db-up, make migrate, python -m app); таблица переменных окружения (имя, обязательна ли, описание); справочник configs/base.yaml по секциям; первый вход Telethon (scripts/telethon_login.py); работа с ботом (команды, добавление источника, модерация); как обновить промпт (повысить PROMPT_VERSION); деплой (docker compose prod), бэкапы (строка cron для scripts/backup.py), отчёт run_report; частые проблемы (FloodWait, сломанный парсер сайта, превышение бюджета).

**Критерий готовности:** Новый человек по README поднимает бота с нуля без вопросов.

**Граничные случаи:** Каждое поле Settings описано в README и .env.example; каждая секция верхнего уровня configs/base.yaml описана в README; в README нет реальных токенов.

**Тесты** (`tests/unit/test_readme.py`): все поля Settings в README и .env.example, все секции base.yaml в README, нет строк, похожих на токен бота.

**Контекст проекта:** Python 3.11+, pydantic-settings (интроспекция полей).

**Файлы:** README.md, .env.example, tests/unit/test_readme.py.

**Стиль проекта:** ruff, mypy strict, docstrings Google Style; инварианты — из CLAUDE.md.

**Ограничения:** Ни один модуль, кроме app/config.py, не читает os.environ. Токены и ключи — SecretStr (не попадают в repr и логи). .gitignore не менять. Новые зависимости, заглушки (TODO, «...») и молчаливый except Exception: pass запрещены.

**Формат ответа:** Полные файлы: README.md, .env.example, tests/unit/test_readme.py. Тесты обязательны. Комментарии — только docstrings Google Style для сложных функций. После кода — таблица [Тест] -> [Критерий]. При нехватке данных сначала перечисли конкретные пробелы, значения не выдумывай (пороги и параметры — из configs/).
