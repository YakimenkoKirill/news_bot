## Задача

Реализуй app/main.py: протокол Component (async start(), async stop(), name), класс Application(components) запускает компоненты по порядку и останавливает в обратном; если start() компонента упал — уже запущенные останавливаются и ошибка пробрасывается. async run() загружает настройки, настраивает логирование, пишет `app.started`, ждёт SIGINT/SIGTERM (asyncio.Event), пишет `app.stopped`. app/__main__.py вызывает run(). Список компонентов на этом шаге пуст — его заполнит шаг сборки приложения.

**Критерий готовности:** python -m app стартует, пишет app.started, по SIGTERM корректно завершается с кодом 0.

**Граничные случаи:** Ошибка в stop() одного компонента логируется и не мешает остановить остальные; повторный сигнал во время остановки не прерывает её.

**Тесты** (`tests/unit/test_main.py`): порядок start/stop, откат при ошибке старта, ошибка в stop не блокирует остальных, остановка по событию.

**Контекст проекта:** Python 3.11+, asyncio, signal.

**Файлы:** app/main.py, app/__main__.py, tests/unit/test_main.py.

**Стиль проекта:** ruff, mypy strict, docstrings Google Style; инварианты — из CLAUDE.md.

**Ограничения:** Ни один модуль, кроме app/config.py, не читает os.environ. Токены и ключи — SecretStr (не попадают в repr и логи). .gitignore не менять. Новые зависимости, заглушки (TODO, «...») и молчаливый except Exception: pass запрещены.

**Формат ответа:** Полные файлы: app/main.py, app/__main__.py, tests/unit/test_main.py. Тесты обязательны. Комментарии — только docstrings Google Style для сложных функций. После кода — таблица [Тест] -> [Критерий]. При нехватке данных сначала перечисли конкретные пробелы, значения не выдумывай (пороги и параметры — из configs/).
