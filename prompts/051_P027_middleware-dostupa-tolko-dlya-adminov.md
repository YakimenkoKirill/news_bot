## Задача

Реализуй AdminOnlyMiddleware(settings, admin_repo) для сообщений и callback-запросов: пропускает пользователя из telegram_admin_ids или AdminRepository.is_admin; остальным отвечает текстом отказа из app/bot/texts.py (не чаще раза в refusal_cooldown_s на пользователя) и прерывает обработку; попытку логирует с user_id без текста сообщения.

**Критерий готовности:** Посторонний пользователь получает отказ; админ проходит к хендлерам.

**Граничные случаи:** Апдейт без from_user (например, пост канала) отбрасывается молча; callback постороннего отвечается answer() с отказом.

**Тесты** (`tests/unit/test_bot_middleware.py`): админ из настроек, админ из БД, посторонний, повторный отказ в пределах паузы, апдейт без пользователя, callback.

**Контекст проекта:** Python 3.11+, aiogram 3.x (BaseMiddleware).

**Файлы:** app/bot/middlewares.py, app/bot/texts.py, tests/unit/test_bot_middleware.py, configs/base.yaml, app/config.py.

**Стиль проекта:** ruff, mypy strict, docstrings Google Style; инварианты — из CLAUDE.md.

**Ограничения:** Ни один модуль, кроме app/config.py, не читает os.environ. Токены и ключи — SecretStr (не попадают в repr и логи). .gitignore не менять. Новые зависимости, заглушки (TODO, «...») и молчаливый except Exception: pass запрещены. Новые ключи конфигурации добавь в configs/base.yaml и в типизированную секцию модели в app/config.py; ключи, помеченные «задаёт человек», не заполняй сам — если их нет в configs/base.yaml, перечисли пробел и остановись. Ключи этого шага: bot.refusal_cooldown_s = 60.

**Формат ответа:** Полные файлы: app/bot/middlewares.py, app/bot/texts.py, tests/unit/test_bot_middleware.py, configs/base.yaml, app/config.py. Тесты обязательны. Комментарии — только docstrings Google Style для сложных функций. После кода — таблица [Тест] -> [Критерий]. При нехватке данных сначала перечисли конкретные пробелы, значения не выдумывай (пороги и параметры — из configs/).
