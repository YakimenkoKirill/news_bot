## Задача

Реализуй check_image(url, http_client, cfg) -> ImageCheck(ok, reason): HEAD-запрос, при 405 или отсутствии заголовков — GET с Range: bytes=0-0; проверка статуса 200/206, Content-Type из image_types и Content-Length <= image_max_bytes.

**Критерий готовности:** Подходящие картинки проходят, неподходящие возвращают понятную причину.

**Граничные случаи:** Нет Content-Length -> ok с предупреждением в логе; редирект на другой домен допустим; таймаут -> ok=false, reason=timeout; url None -> ok=false, reason=no_image.

**Тесты** (`tests/unit/test_media.py`): jpeg, webp, svg (отказ), слишком большая, 404, 405 с переходом на GET, таймаут (aioresponses).

**Контекст проекта:** Python 3.11+, aiohttp, aioresponses.

**Файлы:** app/publisher/media.py, tests/unit/test_media.py, configs/base.yaml, app/config.py.

**Стиль проекта:** ruff, mypy strict, docstrings Google Style; инварианты — из CLAUDE.md.

**Ограничения:** Ни один модуль, кроме app/config.py, не читает os.environ. Токены и ключи — SecretStr (не попадают в repr и логи). .gitignore не менять. Новые зависимости, заглушки (TODO, «...») и молчаливый except Exception: pass запрещены. Новые ключи конфигурации добавь в configs/base.yaml и в типизированную секцию модели в app/config.py; ключи, помеченные «задаёт человек», не заполняй сам — если их нет в configs/base.yaml, перечисли пробел и остановись. Ключи этого шага: publisher.image_types = [`image/jpeg`, `image/png`, `image/webp`]; publisher.image_max_bytes = 5242880 (сверить с документацией Bot API для фото по URL).

**Формат ответа:** Полные файлы: app/publisher/media.py, tests/unit/test_media.py, configs/base.yaml, app/config.py. Тесты обязательны. Комментарии — только docstrings Google Style для сложных функций. После кода — таблица [Тест] -> [Критерий]. При нехватке данных сначала перечисли конкретные пробелы, значения не выдумывай (пороги и параметры — из configs/).
