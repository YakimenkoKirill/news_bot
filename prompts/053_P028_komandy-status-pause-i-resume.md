# Шаг 053 из 070 · P028 · Этап 8 — Бот управления, модерация и сборка приложения

**Задача трекера:** Базовые команды бота
**Результат:** /status, /pause, /resume
**Коммит:** `feat(bot): команды status, pause и resume`
**Как запустить:** откройте репозиторий в Claude Code и напишите: «Выполни @prompts/053_P028_komandy-status-pause-i-resume.md». После коммита: `python prompts/next_step.py --done`.

## Задача

Реализуй app/bot/handlers/status.py: /status — число новостей по статусам (count_by_status), число проблемных источников, расход DeepSeek за сутки и дневной бюджет, флаг паузы, время последней публикации; /pause и /resume меняют настройку paused через SettingsRepository и пишут, кто это сделал, в лог.

**Критерий готовности:** Админ видит актуальное состояние и может остановить и возобновить пайплайн.

**Граничные случаи:** Повторный /pause сообщает, что уже на паузе; публикаций ещё не было -> «нет»; стоимость выводится с 2 знаками.

**Тесты** (`tests/unit/test_bot_status.py`): формат /status, pause/resume и повторы (фейковые репозитории).

**Контекст проекта:** Python 3.11+, aiogram 3.x.

**Файлы:** app/bot/handlers/status.py, tests/unit/test_bot_status.py.

**Стиль проекта:** ruff, mypy strict, docstrings Google Style; инварианты — из CLAUDE.md.

**Ограничения:** Ни один модуль, кроме app/config.py, не читает os.environ. Токены и ключи — SecretStr (не попадают в repr и логи). .gitignore не менять. Новые зависимости, заглушки (TODO, «...») и молчаливый except Exception: pass запрещены.

**Формат ответа:** Полные файлы: app/bot/handlers/status.py, tests/unit/test_bot_status.py. Тесты обязательны. Комментарии — только docstrings Google Style для сложных функций. После кода — таблица [Тест] -> [Критерий]. При нехватке данных сначала перечисли конкретные пробелы, значения не выдумывай (пороги и параметры — из configs/).
