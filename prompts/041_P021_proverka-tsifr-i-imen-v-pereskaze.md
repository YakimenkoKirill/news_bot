## Задача

Реализуй unsupported_facts(source_text, summary) -> list[str]: извлекает из пересказа числа (включая 1 000, 1,5, 1.5, 25%) и слова с заглавной буквы не в начале предложения; число считается подтверждённым, если оно есть в источнике после нормализации записи; имя — если в источнике есть слово с тем же началом из 5 букв (учёт падежей).

**Критерий готовности:** Пересказ без выдуманных цифр и имён даёт пустой список; добавленные — перечисляются.

**Граничные случаи:** Числа в разной записи (1 000 и 1000) совпадают; аббревиатуры (ЕС, NASA) проверяются целиком; пустой пересказ -> пустой список.

**Тесты** (`tests/unit/test_factcheck.py`): русские и английские тексты, формы чисел, падежи имён, аббревиатуры, выдуманные факты.

**Контекст проекта:** Python 3.11+, re.

**Файлы:** app/pipeline/ai/factcheck.py, tests/unit/test_factcheck.py.

**Стиль проекта:** ruff, mypy strict, docstrings Google Style; инварианты — из CLAUDE.md.

**Ограничения:** Ни один модуль, кроме app/config.py, не читает os.environ. Токены и ключи — SecretStr (не попадают в repr и логи). .gitignore не менять. Новые зависимости, заглушки (TODO, «...») и молчаливый except Exception: pass запрещены.

**Формат ответа:** Полные файлы: app/pipeline/ai/factcheck.py, tests/unit/test_factcheck.py. Тесты обязательны. Комментарии — только docstrings Google Style для сложных функций. После кода — таблица [Тест] -> [Критерий]. При нехватке данных сначала перечисли конкретные пробелы, значения не выдумывай (пороги и параметры — из configs/).
