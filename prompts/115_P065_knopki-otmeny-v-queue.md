# Шаг 115 из 117 · P065 · Этап 20 — Отмена постов на модерации

**Задача трекера:** Отмена постов на модерации
**Результат:** В /queue -> «На модерации»: «🚫 Отменить» у поста и «🚫 Отменить все» под списком, оба с подтверждением
**Коммит:** `feat(bot): отмена постов на модерации из /queue`
**Как запустить:** откройте репозиторий в Claude Code и напишите: «Выполни @prompts/115_P065_knopki-otmeny-v-queue.md». После коммита: `python prompts/next_step.py --done`.

## Задача

1. **Клавиатуры** (app/bot/keyboards.py): в QueueActionType — `cancel_review`, `confirm_cancel_review`, `cancel_all`, `confirm_cancel_all`.
   - queue_item_keyboard: для вкладки review (и только для неё) — строка «🚫 Отменить» под «🚀 Опубликовать сейчас»; «◀️ К списку» остаётся последней.
   - Новая `cancel_confirm_keyboard(news_id, tab, page)`: «Да, отменить» (confirm_cancel_review) и «Нет» (возврат к queue_item_keyboard — используй существующее действие cancel, которое уже возвращает исходные кнопки).
   - queue_keyboard: на вкладке review при непустом списке — строка «🚫 Отменить все» (cancel_all) перед навигацией; `cancel_all_confirm_keyboard(tab, page)`: «Да, отменить все» (confirm_cancel_all) и «Нет» (page — вернуть список).
2. **Тексты** (app/bot/texts.py): подтверждение «Отменить пост? Он не будет опубликован и больше не придёт на модерацию.»; «Отменить все посты на модерации ({N})? Их нельзя будет вернуть.»; итоги: «🚫 Отменено — {who}», «Уже обработано: {статус}», «Пост не найден», «Отменено постов: {N}».
3. **Обработчик** (app/bot/handlers/queue.py): QueueDeps получает `review: ReviewDeps` (шаг 114) и batch_size.
   - `cancel_review` -> клавиатура предпросмотра меняется на cancel_confirm_keyboard (edit_reply_markup), callback.answer с текстом подтверждения;
   - `confirm_cancel_review` -> `cancel_review(news_id, by=user_id)`; cancelled -> `mark_message` (app/bot/preview.py) с «🚫 Отменено — @who»; already_done -> mark_message с «Уже обработано: {статус}»; not_found -> mark_message с «Пост не найден»;
   - `cancel_all` -> текст списка меняется на подтверждение с текущим числом постов на модерации (count_prepared) и cancel_all_confirm_keyboard;
   - `confirm_cancel_all` -> сразу callback.answer() (отмена многих постов может занять время), затем `cancel_all_reviews`, ответ «Отменено постов: {N}» и обновлённый список вкладки review;
   - фильтр роутера расширь на новые действия.
4. **app/main.py:** ReviewDeps и pipeline.batch_size — в QueueDeps.
5. **README.md:** в разделе про /queue — как отменить пост или все посты на модерации и что отмена необратима (пост получает статус rejected; в ежедневном отчёте он считается отклонённым модератором).

**Критерий готовности:** Админ в /queue -> «На модерации» отменяет один пост или все сразу, с подтверждением; отменённые посты не публикуются и не возвращаются на модерацию.

**Граничные случаи:** Кнопка «Отменить» не показывается на вкладке «В очереди»; «Отменить все» не показывается при пустой вкладке; пост одобрили в другом окне между открытием и подтверждением -> «Уже обработано: approved», кнопки убраны; «Нет» возвращает исходные кнопки; callback_data каждой новой кнопки не длиннее 64 байт; не-админ не может нажать новые кнопки (middleware доступа).

**Тесты:** `tests/unit/test_bot_queue_cancel.py` — показ кнопок по вкладкам, подтверждение и «Нет», все исходы отмены одного поста, отмена всех с ранним callback.answer, длина callback_data; `tests/unit/test_bot_queue.py` — обнови только ожидаемый набор кнопок вкладки review; `tests/integration/test_queue_publish.py` или новый `tests/integration/test_queue_cancel.py` (маркер integration) — отмена через обработчик с реальной БД и fake-ботом.

**Контекст проекта:** Python 3.11+, aiogram 3.x. Режим одного экрана (шаги 089–092) работает автоматически: ответы идут через обычные отправки и редактирования.
