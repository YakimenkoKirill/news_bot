## Задача

Дополни CLAUDE.md: в нём уже есть раздел «Автопилот» — не меняй его, а замени последний раздел «О проекте» на полные разделы для ИИ-исполнителей: назначение проекта одним абзацем (бот собирает новости из RSS, сайтов и открытых Telegram-каналов, пересказывает через DeepSeek и публикует в Telegram-канал со ссылкой на источник), дерево каталогов из плана, раздел «Инварианты» с пронумерованными правилами: 1) os.environ читает только app/config.py; 2) секреты — SecretStr, никогда не логируются; 3) модули обмениваются данными только через БД и статусы news_items; 4) смена статуса — только через app/domain/status.py; 5) все пороги и параметры — в configs/*.yaml, магических чисел в коде нет; 6) любой сетевой вызов — с таймаутом и повторами tenacity; 7) никаких молчаливых except; 8) в канал уходит только пересказ со ссылкой, дословное копирование запрещено; 9) unit-тесты без сети и БД, интеграционные — с маркером integration; 10) один шаг — один коммит; 11) docstrings Google Style. Раздел «Команды» с целями Makefile. README.md: описание, быстрый старт (make install), ссылка на CLAUDE.md.

**Критерий готовности:** CLAUDE.md и README.md существуют; раздел «Инварианты» содержит не меньше 11 пунктов; каждая команда make из CLAUDE.md есть в Makefile; раздел «Автопилот» не изменён.

**Граничные случаи:** В CLAUDE.md нет команд, которых нет в Makefile; нет упоминаний секретов и реальных токенов.

**Тесты** (`tests/unit/test_docs.py`): наличие раздела «Инварианты» и число пунктов; все `make <цель>` из CLAUDE.md объявлены в Makefile.

**Контекст проекта:** Python 3.11+, pytest.

**Файлы:** CLAUDE.md, README.md, tests/unit/test_docs.py.

**Стиль проекта:** ruff, mypy strict, docstrings Google Style; инварианты — из CLAUDE.md.

**Ограничения:** Ни один модуль, кроме app/config.py, не читает os.environ. Токены и ключи — SecretStr (не попадают в repr и логи). .gitignore не менять. Новые зависимости, заглушки (TODO, «...») и молчаливый except Exception: pass запрещены. Раздел «Автопилот» в CLAUDE.md и каталог prompts/ не менять.

**Формат ответа:** Полные файлы: CLAUDE.md, README.md, tests/unit/test_docs.py. Тесты обязательны. Комментарии — только docstrings Google Style для сложных функций. После кода — таблица [Тест] -> [Критерий]. При нехватке данных сначала перечисли конкретные пробелы, значения не выдумывай (пороги и параметры — из configs/).

1. Перед началом выполни `git status`. Если есть незакоммиченные изменения — остановись и сообщи об этом, ничего не меняй.

