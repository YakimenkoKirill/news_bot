# Шаг 100 из 113 · P056 · Этап 16 — Надёжность и расходы на модель

**Задача трекера:** Расходы на модель
**Результат:** У каждого запроса к модели есть max_tokens; обрезанный ответ считается плохим
**Коммит:** `fix(ai): ограничение длины ответа модели`
**Как запустить:** откройте репозиторий в Claude Code и напишите: «Выполни @prompts/100_P056_limit-dliny-otveta-modeli.md». После коммита: `python prompts/next_step.py --done`.

## Задача

В DeepSeekClient._request (app/pipeline/ai/client.py) не передаётся max_tokens: при сбое модель может писать до лимита контекста, а платим за каждый выходной токен.

1. **Конфигурация:** `ai.max_output_tokens: 800` (int, ge=1) — с запасом для заголовка 90, пересказа 700 символов, хэштегов и JSON-обёртки. Комментарий в yaml с этим расчётом.
2. **Клиент:** `chat_json(messages, *, max_tokens: int | None = None)`; по умолчанию — ai.max_output_tokens. Передавай `max_tokens` в `chat.completions.create`.
3. **Обрезанный ответ:** если `choices[0].finish_reason == "length"` — AiResponseError("ответ модели обрезан по max_tokens"). Это существующая ветка «плохой ответ»: один повтор, затем failed с reason bad_ai_response. Токены обрезанного ответа учитываются в стоимости так же, как сейчас учитываются токены неудачной попытки.
4. Лог `ai.truncated` с prompt_tokens и completion_tokens.

**Критерий готовности:** Ни один запрос к модели не может вернуть больше ai.max_output_tokens токенов; обрезанный ответ не попадает в канал.

**Граничные случаи:** finish_reason отсутствует (провайдер не прислал) -> считается нормальным; finish_reason = 'stop' -> нормально; 'length' на первой попытке и нормальный ответ на второй -> пост создаётся; 'length' дважды -> failed.

**Тесты:** `tests/unit/test_ai_client.py` — max_tokens передаётся, переопределение аргументом, finish_reason length -> AiResponseError; `tests/unit/test_ai_processor.py` — обрезанный ответ ведёт себя как плохой ответ; `tests/unit/test_config.py` — новый ключ.

**Контекст проекта:** Python 3.11+, openai SDK (OpenAI-совместимый API TeamoRouter / DeepSeek).

**Файлы:** app/pipeline/ai/client.py, app/pipeline/ai/processor.py (только если нужно для логов), app/config.py, configs/base.yaml, тестовые файлы из списка выше.
