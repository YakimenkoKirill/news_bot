# Шаг 058 из 070 · P031 · Этап 8 — Бот управления, модерация и сборка приложения

**Задача трекера:** Модерация черновиков
**Результат:** Обработка решений модератора
**Коммит:** `feat(bot): обработка кнопок модерации`
**Как запустить:** откройте репозиторий в Claude Code и напишите: «Выполни @prompts/058_P031_obrabotka-knopok-moderatsii.md». После коммита: `python prompts/next_step.py --done`.

## Задача

Реализуй app/bot/handlers/moderation.py: «Опубликовать» -> approved; «Отклонить» -> rejected; «Позже» -> set_snooze(now + snooze_min); «Изменить» -> FSM: новый текст пересказа (проверка fit_post), update_summary с edited_by и approved. Сообщение с кнопками редактируется: кнопки убираются, дописывается решение и кто его принял.

**Критерий готовности:** Каждое решение модератора меняет статус поста и видно в чате.

**Граничные случаи:** Пост уже обработан другим админом -> ответ «Уже обработано: статус» без изменений (StaleStatusError); слишком длинный новый текст -> повтор вопроса с лимитом.

**Тесты** (`tests/unit/test_bot_moderation.py`): каждая кнопка, повторное решение, редактирование и длинный текст.

**Контекст проекта:** Python 3.11+, aiogram 3.x.

**Файлы:** app/bot/handlers/moderation.py, app/bot/states.py, tests/unit/test_bot_moderation.py, configs/base.yaml, app/config.py.

**Стиль проекта:** ruff, mypy strict, docstrings Google Style; инварианты — из CLAUDE.md.

**Ограничения:** Ни один модуль, кроме app/config.py, не читает os.environ. Токены и ключи — SecretStr (не попадают в repr и логи). .gitignore не менять. Новые зависимости, заглушки (TODO, «...») и молчаливый except Exception: pass запрещены. Новые ключи конфигурации добавь в configs/base.yaml и в типизированную секцию модели в app/config.py; ключи, помеченные «задаёт человек», не заполняй сам — если их нет в configs/base.yaml, перечисли пробел и остановись. Ключи этого шага: moderation.snooze_min = 60.

**Формат ответа:** Полные файлы: app/bot/handlers/moderation.py, app/bot/states.py, tests/unit/test_bot_moderation.py, configs/base.yaml, app/config.py. Тесты обязательны. Комментарии — только docstrings Google Style для сложных функций. После кода — таблица [Тест] -> [Критерий]. При нехватке данных сначала перечисли конкретные пробелы, значения не выдумывай (пороги и параметры — из configs/).
