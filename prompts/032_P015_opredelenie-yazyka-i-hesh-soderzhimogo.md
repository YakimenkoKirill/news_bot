## Задача

Дополни app/pipeline/normalizer.py: detect_language(text) -> `ru` | `en` | `unknown` по доле кириллических и латинских букв с порогом lang_ratio; content_hash(text) — sha256 от текста в нижнем регистре без пунктуации и лишних пробелов, ё->е; normalize_item(news) -> NormalizedFields(clean_text, canonical_url, language, content_hash).

**Критерий готовности:** Тексты, отличающиеся только регистром, пунктуацией и пробелами, имеют одинаковый хеш.

**Граничные случаи:** Текст без букв -> unknown; смешанный текст ниже порога -> unknown; хеш стабилен между запусками.

**Тесты** (`tests/unit/test_normalizer_item.py`): русский, английский, смешанный, без букв; равенство и неравенство хешей; normalize_item.

**Контекст проекта:** Python 3.11+, hashlib.

**Файлы:** app/pipeline/normalizer.py, tests/unit/test_normalizer_item.py, configs/base.yaml, app/config.py.

**Стиль проекта:** ruff, mypy strict, docstrings Google Style; инварианты — из CLAUDE.md.

**Ограничения:** Ни один модуль, кроме app/config.py, не читает os.environ. Токены и ключи — SecretStr (не попадают в repr и логи). .gitignore не менять. Новые зависимости, заглушки (TODO, «...») и молчаливый except Exception: pass запрещены. Новые ключи конфигурации добавь в configs/base.yaml и в типизированную секцию модели в app/config.py; ключи, помеченные «задаёт человек», не заполняй сам — если их нет в configs/base.yaml, перечисли пробел и остановись. Ключи этого шага: normalize.lang_ratio = 0.6.

**Формат ответа:** Полные файлы: app/pipeline/normalizer.py, tests/unit/test_normalizer_item.py, configs/base.yaml, app/config.py. Тесты обязательны. Комментарии — только docstrings Google Style для сложных функций. После кода — таблица [Тест] -> [Критерий]. При нехватке данных сначала перечисли конкретные пробелы, значения не выдумывай (пороги и параметры — из configs/).
