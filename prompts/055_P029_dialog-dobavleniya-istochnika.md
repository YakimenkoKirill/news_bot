# Шаг 055 из 070 · P029 · Этап 8 — Бот управления, модерация и сборка приложения

**Задача трекера:** Управление источниками через бота
**Результат:** Диалог добавления источника (FSM)
**Коммит:** `feat(bot): диалог добавления источника`
**Как запустить:** откройте репозиторий в Claude Code и напишите: «Выполни @prompts/055_P029_dialog-dobavleniya-istochnika.md». После коммита: `python prompts/next_step.py --done`.

## Задача

Реализуй app/bot/states.py (AddSource) и app/bot/handlers/source_add.py: /add_source -> тип (кнопки rss/web/tg) -> адрес (rss и web — http(s) URL; tg — @username или t.me/username, приводится к username) -> имя -> интервал в минутах (не меньше min_interval_min) -> режим модерации -> для web JSON селекторов (валидация WebSelectors) -> подтверждение с кнопкой «Пробный сбор» (вызов сборщика без сохранения, показ первых 3 заголовков) и «Сохранить». /cancel выходит из диалога на любом шаге.

**Критерий готовности:** Админ добавляет источник любого типа через диалог с проверкой ввода.

**Граничные случаи:** Неверный ввод повторяет вопрос с причиной; дубль URL -> сообщение и выход; ошибка пробного сбора показывается, но не мешает сохранить.

**Тесты** (`tests/unit/test_bot_source_add.py`): полный проход для каждого типа, ошибки ввода, /cancel, дубль, пробный сбор успешный и с ошибкой.

**Контекст проекта:** Python 3.11+, aiogram 3.x (FSM, StatesGroup).

**Файлы:** app/bot/states.py, app/bot/handlers/source_add.py, tests/unit/test_bot_source_add.py, configs/base.yaml, app/config.py.

**Стиль проекта:** ruff, mypy strict, docstrings Google Style; инварианты — из CLAUDE.md.

**Ограничения:** Ни один модуль, кроме app/config.py, не читает os.environ. Токены и ключи — SecretStr (не попадают в repr и логи). .gitignore не менять. Новые зависимости, заглушки (TODO, «...») и молчаливый except Exception: pass запрещены. Новые ключи конфигурации добавь в configs/base.yaml и в типизированную секцию модели в app/config.py; ключи, помеченные «задаёт человек», не заполняй сам — если их нет в configs/base.yaml, перечисли пробел и остановись. Ключи этого шага: collectors.min_interval_min = 5.

**Формат ответа:** Полные файлы: app/bot/states.py, app/bot/handlers/source_add.py, tests/unit/test_bot_source_add.py, configs/base.yaml, app/config.py. Тесты обязательны. Комментарии — только docstrings Google Style для сложных функций. После кода — таблица [Тест] -> [Критерий]. При нехватке данных сначала перечисли конкретные пробелы, значения не выдумывай (пороги и параметры — из configs/).
