## Задача

Реализуй apply_filters(item, now, keywords: KeywordSets, cfg) -> FilterDecision(passed, reason). Порядок: published_at старше max_age_h -> too_old; язык не из allowed_languages -> language:<код>; стоп-слово в заголовке или тексте -> stop_word:<слово>; список include не пуст и ни одно слово не найдено -> no_keyword. Поиск по границам слов, без учёта регистра, ё = е; фразы из нескольких слов поддерживаются.

**Критерий готовности:** Каждая новость получает решение и понятную причину отказа.

**Граничные случаи:** published_at None -> используется created_at; пустые списки слов ничего не отсекают; слово внутри другого слова не совпадает.

**Тесты** (`tests/unit/test_filters.py`): каждая причина отказа, порядок проверок, границы слов, ё/е, фразы, пустые списки.

**Контекст проекта:** Python 3.11+, re.

**Файлы:** app/pipeline/filters.py, tests/unit/test_filters.py, configs/base.yaml, app/config.py.

**Стиль проекта:** ruff, mypy strict, docstrings Google Style; инварианты — из CLAUDE.md.

**Ограничения:** Ни один модуль, кроме app/config.py, не читает os.environ. Токены и ключи — SecretStr (не попадают в repr и логи). .gitignore не менять. Новые зависимости, заглушки (TODO, «...») и молчаливый except Exception: pass запрещены. Новые ключи конфигурации добавь в configs/base.yaml и в типизированную секцию модели в app/config.py; ключи, помеченные «задаёт человек», не заполняй сам — если их нет в configs/base.yaml, перечисли пробел и остановись. Ключи этого шага: filters.max_age_h = 24; filters.allowed_languages — задаёт человек.

**Формат ответа:** Полные файлы: app/pipeline/filters.py, tests/unit/test_filters.py, configs/base.yaml, app/config.py. Тесты обязательны. Комментарии — только docstrings Google Style для сложных функций. После кода — таблица [Тест] -> [Критерий]. При нехватке данных сначала перечисли конкретные пробелы, значения не выдумывай (пороги и параметры — из configs/).
